# Repository instructions

After every CodeBurn source change, rebuild and update every installed CodeBurn CLI before finishing. Use the configured external build tree at `/mnt/kingston/builds/rebroad/src/codeburn.build`: synchronize the complete source tree with `cpto --nogit`, then run `npm run build:cli` with the current source commit in `CODEBURN_COMMIT`. The build script updates and verifies installed CodeBurn packages for every Node version under `~/.nvm/versions/node`, the Node executable running the build, and Node/CodeBurn executables resolved from `PATH`. Verify that the active `PATH` CodeBurn command, when present, and every discovered installed executable report the current commit. Some installs may link to the external build tree; others are regular global copies. Do not assume rebuilding the build tree updates regular copies, and do not stop after committing or pushing.
